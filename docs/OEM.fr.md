# OEM (resume FR)

Doc EN : [OEM.md](OEM.md)

## Règles

- **BitLocker On** ≠ Locked : l’outil suspend les protecteurs (sans déchiffrer).
- **BitLocker Locked** : déverrouiller d’abord.
- **Toshiba / Dynabook HDD Password** : déverrouiller dans le BIOS.
- Clé **MSDM** OEM reste sur la carte mère — ne pas formater pour réactiver.
- Partitions recovery Acer/Asus/HP/Dell/Lenovo : préservées ; nouvelle ESP créée si besoin.
